Privacy

Emma Keyboard does not send every keystroke to a server. Settings, learned words, personal dictionary, recent emoji and clipboard history stay in this browser. Password fields are never learned or autocorrected. Voice recognition depends on your browser and may use its speech service. Translation API requests, when configured, send only the text you translate.
